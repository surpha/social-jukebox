# HARNESS.md — Dev, test & deploy harness

How to build, run, and ship Social Jukebox. Keep in sync with `render.yaml`, `requirements.txt`,
and the commands in [AGENTS.md](AGENTS.md).

## Local development
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # fill in real values before running
uvicorn app.main:app --reload
```
App serves on http://localhost:8000. Interactive API docs at http://localhost:8000/docs.

### Required external services
1. **Spotify Developer app** (https://developer.spotify.com/dashboard)
   - Add redirect URIs matching `SPOTIFY_REDIRECT_URI` and `SPOTIFY_LOGIN_REDIRECT_URI`
     (e.g. `http://localhost:8000/api/spotify/callback` and
     `http://localhost:8000/api/auth/spotify/callback`).
   - A Spotify **Premium** account is required for playback control.
2. **PostgreSQL** — Supabase free tier in prod, or a local Postgres for dev. The URL must use the
   `postgresql+asyncpg://` scheme.

## Configuration
Environment variables are defined in `app/config.py` and documented in [ARCHITECTURE.md](ARCHITECTURE.md) §9.
When adding a variable, update **all** of: `app/config.py`, `.env.example`, and `render.yaml`.

Generate a secret key: `openssl rand -hex 32`. Note: changing `SECRET_KEY` invalidates all stored
(encrypted) Spotify tokens.

## Database
- Schema is created on startup by `init_db()` (`Base.metadata.create_all`).
- There is **no Alembic**. Post-initial-schema columns are added via idempotent
  `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` in `init_db()`. Add new ones there.
- Active-space workers are relaunched on startup via `WorkerManager.restart_active_workers()`.

## Tests
No automated tests exist yet. If you add them:
- Use `pytest` (+ `pytest-asyncio` for async paths).
- Add the dependency to `requirements.txt` and the run command here and in [AGENTS.md](AGENTS.md).

## Deployment (Render)
1. Push to GitHub.
2. Render deploys via the `render.yaml` blueprint:
   - `buildCommand: pip install -r requirements.txt`
   - `startCommand: uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - `PYTHON_VERSION: 3.11.9`
3. Set the `sync: false` env vars in the Render dashboard (`DATABASE_URL`, Spotify creds,
   `APP_URL`, redirect URIs). `SECRET_KEY` is auto-generated by Render.
4. Update Spotify app redirect URIs and `APP_URL` to the deployed URL.

## Manual smoke test
1. Open `/`, "Continue with Spotify", authorize → lands on `/dashboard`.
2. Create a space, activate it, open the QR / `/s/{code}`.
3. From a second device/browser: search, add a track, up/down-vote.
4. Start playback in Spotify; within ~5s of a track change the top-voted song should be queued.
